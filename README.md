1. Introduction
         Hangman is a simple text-based word-guessing game developed using Python. In this game, the computer selects a random word, and the player must guess the word by entering one letter at a time.

2. Objective
         The main objective is to create a Python program where the player guesses a hidden word within a limited number of incorrect attempts.
   
3. How the Game Works
   1.The computer selects a random word from a list of 5 predefined words.
   2.The selected word is displayed as blank spaces (underscores).
   3.The player enters one letter at a time.
   4.If the guessed letter is correct, it appears in the correct position.
   5.If the guessed letter is incorrect, the player loses one chance.
   6.The player gets a maximum of 6 incorrect guesses.
   7.If the player guesses the complete word, they win.
   7.If all 6 incorrect guesses are used, the game ends.
